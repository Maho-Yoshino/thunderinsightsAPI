# War Thunder Stats Converter

This Python script converts the binary stat content of War Thunder game files into JSON format. It is inspired by [WtTools](https://github.com/Keksilton/WtTools) and designed to streamline the process of extracting data from `.blk` or `.bin` files commonly used in the game.

## Usage Example:

```bash
python wt-bin-parser.py -i binary-content.blk
```

Use -h for the list of supported parameters.
